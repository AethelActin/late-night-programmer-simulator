# 深夜程序员模拟器 v0.1.0-preview · 实验性试玩版

**这是一个仍不成熟的个人实验项目，可能有 Bug、动画衔接或性能问题，不是正式商业成品。欢迎试玩和反馈。**

## 下载与运行

Windows 玩家下载附件 `LateNightProgrammerSimulator.exe` 后双击运行，无需安装 Python。第一次启动会解压内置素材，请耐心等待。`Source code` ZIP 主要用于阅读源码，不能直接作为游戏运行。

菜单可切换中英文；选择时长后开始。可静静观看，也可点击事件选项。Esc 或左下角退出按钮打开返回菜单确认框；确认框打开时局内暂停。

## 当前内容

- 像素风深夜编程场景、猫、雨天及随机事件。
- 氛围、理智、项目进度三项数值，理智耗尽或进度完成后结束。
- 动画链、双语界面、按帧缓存与 Windows 单文件打包。
- 采用 AI 辅助开发；动画由作者生成、剪辑、抽帧和集成。

## 已知限制

- 当前公开版没有背景配乐，未包含原项目中的第三方歌曲。
- 没有存档、账号、联网、广告或真实 AI 调用；关闭后进度不保留。
- 未签名；只在本机 Windows 11 x64 检查，低配电脑、其他系统未验证。
- 长时段的实际局长受随机事件影响，动画转场和性能仍可改进。
- 原始运行素材未单独放入源码仓库；源码运行需自行配置资源，见素材说明。
