# 深夜程序员模拟器：项目说明、修复与发布路线

**当前发布范围更新（2026-10-19）：作者已授权公开实验性试玩版。README 与 v0.1.0-preview 版本说明为当前玩家入口；下文保留先前准备与验证记录。公开 EXE 排除原有全部背景音乐和 Zpix，使用现有 OFL 字体并附许可文本；旧完整包继续留在本地。**

更新时间：2026-10-19。适用对象：作者、接手开发者、试玩组织者；本文件不代表已签订平台合作或具备商业授权。

当前名称：深夜程序员模拟器 / Late Night Programmer Simulator。旧名称 Vibe Coding Simulator、工程代号 VCS 只用于历史记录；新的打包名为 LateNightProgrammerSimulator。GitHub 展示准备见 [GITHUB_RELEASE.md](GITHUB_RELEASE.md)，本轮平台调查见 [PLATFORM_COOPERATION.md](PLATFORM_COOPERATION.md)。

## 1. 当前判断

**保留现有 Python + pygame 方案，完成稳定性收尾后先验证 Windows 试玩；现在不建议把原 EXE 直接当作商业发行包。** 这款作品的优势是深夜编码场景、猫与雨的陪伴感，以及等待 AI 时的自嘲。先证明有人愿意打开和再次打开，比先接广告或换引擎更有价值。

本轮按“代码体检 → 生命周期与性能修复 → 回归和实际画面检查 → 文档和候选打包”执行。原有 `dist/VibeCodingSimulator.exe` 保留，修复构建放在 `dist/candidate/`。未上传、投稿、推送或公开发布。

公开分发前仍需完成素材许可核查、选择代码许可证，并在另一台电脑上验收。候选 EXE 继续包含原素材，用于本地对照和检查，不能把打包成功等同于商业发布通过。

## 2. 游戏定位与当前内容

一句话介绍：**等 AI 写代码的时候，让另一个深夜程序员和他的猫陪你待一会。**

- 用户：程序员、AI 编程用户、喜欢像素场景和轻量陪伴的人。
- 使用场景：等待生成、编译或下载时，安静观看几分钟；也可主动选择事件。
- 当前机制：氛围影响画面，理智随时间下降，项目进度被动增长；事件可能改变三项数值。
- 场景：无雨、下雨和结束；16 条动画序列，共 662 张 1280×720 PNG。
- 内容：双语 UI 与事件、猫动画链、雨天变化、背景音乐、事件选择和日志。
- 结束：理智耗尽，或项目进度达到 100%；结束后可继续停留或返回菜单重开。
- 当前没有：存档、账号、在线排行榜、真实 AI 请求、网络通信、广告 SDK、收入统计。

短、正常、长时段的速度沿用原值，没有重新设计经济系统：

| 模式 | 理智下降/秒 | 进度增长/秒 | 不计事件时理智归零 | 不计事件时进度完成 |
| --- | ---: | ---: | ---: | ---: |
| 短 | 0.15 | 0.30 | 约 6.67 分钟 | 约 5.56 分钟 |
| 正常 | 0.08 | 0.25 | 12.5 分钟 | 约 6.67 分钟 |
| 长 | 0.01 | 0.03 | 100 分钟 | 约 55.56 分钟 |

初始理智为 60。以上是除法推演，不是实际局长承诺；事件会恢复理智、增减进度。本轮恢复了原本未被调度的文字事件，其效果开始生效，因此时长分布与旧 EXE 可能不同，需试玩反馈后再平衡。

## 5. 技术结构与维护方式

```text
main.Game                     窗口 / 菜单 / 输入 / 模态 / 缩放
  ├─ GameSession              一局生命周期与结局判定
  │    ├─ EventSystem         事件筛选 / 游戏计时 / 效果结算
  │    ├─ StateManager        域 / 动画链 / 转场
  │    └─ SpritePlayer        帧计时 / 按帧解码 / LRU 缓存
  ├─ AudioManager             按需加载 / 淡入 / 静音
  └─ ui + lang + font_manager 布局 / 翻译 / 字体
```

- `GameSession.stats` 在重开时原地清空、填入初值，事件系统始终持有同一字典。
- 重开同时清理当前事件、天气计时、日志、动画链、局内数值和 UI 临时状态；语言与静音在同次运行中保留。
- 事件基于传入的游戏时间 `dt`，不再读取墙钟；确认框打开时不推进局内时间。帧间隔上限 0.1 秒，挂起恢复不会追赶整段离线时间；长时间低帧率会使游戏时间慢于实际时间。
- 选项一次点击即应用、关闭；有选项时，动画结束和任意按键不会代替玩家选择。约 8 秒超时中性关闭，适合无人操作。
- 无选项动画事件可在动画结束、手动关闭或超时后结束；手动关弹窗不截断猫动画链。
- 场景切换在事件开始时同步，避免动画已经下雨而数据仍无雨。雨至少 30 游戏秒后允许雨停，60 秒后优先安排雨停，已有弹窗或动画链可能延后该事件。
- 进入结局优先于普通动画，丢弃旧弹窗，避免旧效果把结束域改回雨天。理智耗尽不再调度事件，进度完成只调度 `done` 事件。
- 资源通过 `resource_path()` 定位，支持源码和 PyInstaller 单文件；不依赖启动时的当前目录。

修改事件时：使用唯一 `id`，检查 `domain`、条件、效果和翻译；旧 `sanity` 字段会规范为内部 `reality`。无动画/选项且未指定 `severity` 的条目进入日志池，有动画/选项的进入弹窗池。日志最多保留 6 条。`sunrise` 暂无独立动画域，保留其数值效果而不切入未定义场景；`audio`、`visual` 特效标记尚未实现。

## 6. 本轮修复记录

| 原有问题 | 修复后的行为 |
| --- | --- |
| 返回菜单重新赋值 stats，事件系统还写旧字典 | 原地重置并集中在 GameSession 管理 |
| 动画链锁可能阻止进入结局，最后一段提前解锁 | 结局可中断；链最后一段播完后才解锁 |
| 动画结束分支优先于选项输入，可能关掉选择事件 | 选择与动画分开；一次选择原子结算并关闭 |
| 退出框下层仍可能响应点击，局内继续走时 | 模态输入优先，确认期间冻结局内更新 |
| 游戏计时和事件冷却混用墙钟 | 同一游戏时间，暂停后事件不会突然到期 |
| 结束时旧事件残留，雨天数据和动画切换不同步 | 清理旧事件，天气开始即同步 |
| 部分 events.json 条目被分类为日志却永不进入日志池 | 合并可用日志，规范旧字段，应用对应效果 |
| 动画计时切换未清空，末帧未播满即被判定结束 | 切换清零，末帧持续完整帧时长 |
| 启动一次性解码全部 PNG；音乐全量解码 | 动画 96 帧 LRU，音乐仅播放时解码 |
| done 音乐被低理智优先级覆盖；静音冻结淡入状态 | 结局优先，静音仍更新淡入状态；无声卡可运行 |
| 英文选项横排越出面板，小窗口布局溢出 | 选项竖排；固定逻辑画布等比缩放并映射鼠标 |
| 雨中空闲→猫醒来未遵循约定淡入 | 按现有动画规则修正 |

中文成为本地试玩默认语言，英文仍可在菜单切换；背景与原始素材保持原文件。右下角黑色遮块是作者用于遮住 AI 动画可见水印的既有设计，已按作者说明恢复；遮罩与画面等比缩放，不改变素材文件。

环境：Windows 11 x64、Python 3.13.0、pygame 2.6.1、PyInstaller 6.20.0。命令均从项目根执行。
